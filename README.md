# Guandan Training Project

Independent pure-Python GuanDan training project.

- Rules and game engine are implemented independently in this repository.
- Action protocol uses stepwise token construction with explicit commit.
- Training target: PyTorch MARVEL-style policy/value training, then Kaggle execution.
- FableDan is not a runtime or source dependency.

Project status is tracked in `project_status/STATUS.yaml` and acceptance evidence in `project_status/history/`.
