# A01 牌与组合验收

## 范围

在构建任何牌局引擎之前，验证独立的双副牌实体牌模型以及 v1 的十类牌型组合。

## 必需命令

```powershell
python scripts/run_acceptance.py --stage A01
```

## 必需证据

- 共有 108 张唯一的实体牌，分成每组 27 张牌时保持牌的守恒。
- 顺子恰好由五张牌组成，连对恰好由三组对子组成，连三恰好由两组三张同点数牌组成。
- 支持 A 作为低牌的连牌窗口，并拒绝 JQKA2/KA2 这类跨越首尾的连牌。
- 支持同种王牌组成的对子和四王，拒绝双王火箭。
- 同花顺和炸弹层级。
- 验证级牌/逢人牌声明、逢人牌对非王牌的替代，以及实体牌分配关系的保留。
- 拒绝级牌上下文不匹配的情况和伪造声明。
- 单元测试、属性测试和验收测试全部通过，且没有跳过（skipped）或预期失败（xfail）的测试。

## 人工审查门槛

监督代理必须检查牌型组合 API 和代码差异，运行专项测试和全量测试，并确认测试由需求驱动，而不只是枚举当前实现中的枚举成员。
