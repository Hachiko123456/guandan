# A11 本地性能优化与 Kaggle 短测门槛

## 范围与原则

本轮优化现有规则/环境和数据供给；不修改奖励、动作集合、模型结构和学习目标，不删除现有训练进度。Kaggle 不自动启动：本机只能验证 RTX 3050 Ti 单卡与 CPU；T4 x2 结果必须由真实远端短测获得。

## 必须通过的本地门槛

1. 固定基线源码、同一权重、同一任务种子和同一局数做前后对照，不拿不同机器比较当加速比。
2. 牌型识别覆盖 13 个级牌、108 张物理牌、自然/替代逢人牌声明、不可比牌型和炸弹顺序；合法动作顺序及字段与参考实现一致。
3. 规则层参考语料和完整对局对照；CPU 固定策略采样轨迹完全一致。GPU 数值差异单独注明，不伪称跨设备逐位复现。
4. 不删除合法性验证、牌守恒、actor/critic 信息隔离、终局/截断、事务回滚和恢复测试。内部已验证声明可复用结果，公开不可信声明入口仍验证。
5. 记录环境、推理、学习更新与端到端时间。性能目标是同工作负载至少 2×，不是 GPU 空转指标；没有实测收益不放行。
6. 本地 CPU/RTX 3050 Ti 各做冻结策略评估和短训练，记录真实 games/tokens/updates、显存和失败信息。
7. 旧 checkpoint 可以继续加载/评估，现有完整状态的 compatible resume 通过真实测试；不为吞吐改变策略版本、采样顺序或有效更新量。
8. 修复遥测在 Torch 部分导入时访问 cuda 的启动竞态。

## Kaggle 短测门槛

- 默认 plan-only，显式 execute 才运行；单次总预算不超过600秒，包含初始化，超时回收本次拥有的子进程。
- 同一环境、相同固定全局任务量比较单卡与双卡，不把两个不同规模相除。
- 只统计真实完成工作，失败/超时/不同规模不得计算“通过”的 speedup。
- 双卡吞吐目标至少1.5×，未达标不推荐双卡长跑；利用率仅作诊断，不保证100%或制造无效计算。
- 不包含自动正式长训练/评估；只有用户审查结果后才使用推荐配置长跑。
