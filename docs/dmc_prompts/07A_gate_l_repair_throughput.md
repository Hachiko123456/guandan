# DMC 阶段 07A：吞吐优化（Gate L 失败修复之一）

日期：2026-10-25 · 状态：待执行 · 依据：Gate L 实测 0.711 局/秒 < 0.85 下限（`runs/kaggle_pipeline/dmc-gate-l-3f3fc5fc865f2d6e614aaf41/gate_l_results_manual.zip`）

## 目标（量化）

单进程持续吞吐从 **0.711 局/秒 → ≥1.5 局/秒**（争取 2.5+）。学习语义零改动：锁定表（`00_DMC_MIGRATION_PLAN.md` 第 2 节）的全部字段不得变化；`num_envs`、cycle 大小、进程拓扑是**运营参数**，允许调整。

## Gate L 实测事实（优化依据，不得凭空猜测热点）

- 34 cycles / 8,708 局 / 12,241s；采集阶段约 1 局/秒，每 cycle 训练额外 50~330s；
- 每局样本数从 130（开局网络偏好对子、对局长）降到 ~50（策略变强、对局缩短）——吞吐会随训练自然提升，本阶段优化的是管线固有开销；
- 阶段2基准：枚举单线程均值 1.14ms/决策（p50=14.9µs，max=858ms 大首出），纯枚举上限 ≈274 决策/秒 ≈ 7 局/秒——**Python 枚举+环境步进是串行瓶颈**；
- 评估对局 0.67~0.83 局/秒（同样环境受限）。

## 优化杠杆（按优先级实施，每项必须独立可测、独立提交）

1. **双卡分工：采集与训练重叠**（预计最大收益，~2x）。T4×2 上：GPU0 跑 learner，GPU1 跑采集侧 Q 推理；每 cycle 结束同步一次权重（参照 FableDan `train_fast.py` 的 infer_server 广播模式，但同步实现即可，不强制异步队列）。实现为 `dmc/parallel.py` 或等价模块；单卡退化路径保留（本机 3050 Ti 单卡验证用）。
2. **envs 32→64（或 96）**：lockstep 批更大，摊薄每步前向与 Python 循环开销。
3. **cycle 256→512 局**：减少 cycle 边界的检查点/求值开销（注意：允许，因 replay 容忍陈旧性；梯度比按样本仍为 1.0）。
4. **（可选，若前三项不足 1.5）C++ 候选枚举移植**：`nanopokerlib/cpp/` 增加纯枚举导出 + pybind 绑定，与 Python oracle 做差分模糊测试（复用 M04/M05 差分验收模式）。仅当 1-3 项实测不足时才做。

## 明确禁止

- 改动锁定表任何字段（ε 计划、梯度比 1.0、AdamW 1e-4/wd0、buffer 500k、z 语义、单候选不采样）；
- 改动观测编码语义（那是 07B 的事）；
- 以削弱校验/健康计数换速度。

## 验收标准

1. 本机（3050 Ti，单卡退化路径）基线复测：先跑 stage-4 冒烟配置 100 局记录基线 games/s，改动后**同配置 ≥2x**；
2. `pytest tests/dmc -q` 全绿 + 新增吞吐回归测试（如"双卡权重同步后 Q 输出一致"或单卡等价路径测试）；
3. 同 seed 确定性保持（同配置两次短跑行为序列一致）；
4. REPORT 记录每项杠杆的单独实测收益与最终组合吞吐（本机数字 + 外推 Kaggle 预期）。

## 交付物

代码 + 测试 + `runs/dmc_stage07a_<date>/REPORT.md`。Kaggle 真实吞吐数字由 Gate L 重跑（05 门槛不变）实测，不单独烧 session。

## Gate L 重跑附加规则（写入重跑交付的 plan；2026-10-25 按 07A 实测修正）

早停口径改为**进度外推制**：前 1,000 局完成后按当时持续速度外推全程总局数，**外推 < 12,000 局才早停**（≈持续速度 < 0.95 局/秒）；≥ 0.95 局/秒则继续跑满预算，由终点实测局数对照 05 门槛判定。原"<1.2 局/秒即早停"作废——07A 实测外推吞吐 1.0~1.15 局/秒且开局对局偏慢，该线会误触发。
